1. Acesso administrativo

A chave é utilizada apenas nesta aba e não é gravada no navegador.

2. Cadastre os cinco fornecedores

Os produtos da loja não precisam ser associados a fornecedores individuais. Cadastre os cinco nomes e seus WhatsApps comerciais, com código do país (DDI), por exemplo +55 ou +86. Os números ficam no banco privado D1.

Carregue os fornecedores para começar.

Use as setas ↑ e ↓ na coluna Prioridade para mudar a posição. Clique em SALVAR ORDEM para gravar a sequência no Cloudflare. A posição 1 será consultada primeiro quando a automação for autorizada.

O número completo não aparece novamente após salvar (somente os 4 últimos dígitos). Para corrigir, digite o novo número em “Atualizar contato”. Sem autorização, o número fica cadastrado, mas não é elegível para envio automatizado. A Cloud API ainda está desligada.

3. Fluxo planejado de estoque

  1. O pedido pago entra na fila de consulta.
  2. O primeiro fornecedor recebe foto e resumo dos produtos, somente após habilitar a API oficial.
  3. Uma resposta inequívoca de estoque indisponível move o pedido ao próximo fornecedor.
  4. A disponibilidade deve ser confirmada antes do envio dos dados de entrega.
  5. Se todos recusarem, a loja sinaliza revisão manual para alternativa ou reembolso.

Nesta etapa, o WhatsApp, os pagamentos reais e os pagamentos a fornecedores permanecem desativados.
